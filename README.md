# منظومة Neama AI (نعمه أي) - الإصدار السيادي المستقل (v5.0 NextGen)

نظام ذكاء اصطناعي سيادي متقدم للهندسة المعمارية البرمجية، البرمجة الذاتية، وإدارة السرب المستقل للوكلاء الأذكياء.

---

## 🚀 المميزات الرئيسية
- **التوليد والبرمجة الذاتية**: توليد كود نظيف، معياري ومتوافق مع أفضل الممارسات الهندسية.
- **التحليل المعماري والأمني**: تدقيق الكود، فحص الثغرات (SAST, SCA, OWASP Top 10, SSRF, CSRF)، وسياسات Zero-Trust.
- **إدارة السرب المستقل (72 وكيلاً)**: تنسيق المهام المعقدة، التعلم المعزز التكراري (RCI)، وتكامل الحاويات.
- **المراقبة والاستجابة الحية (SLA & Latency)**: تتبع المقاييس عبر Prometheus، واختبارات التعافي والنسخ الاحتياطي التلقائي (AES-256).
- **المحرك الصوتي والعاطفي التفاعلي**: محاكاة ونمذجة المشاعر وتحليل النبرة والاستجابة الصوتية الفورية.

## 📁 الهيكل العام للمشروع
```
├── app/
│   ├── advanced_modules/       # وحدات الحوكمة، المرونة، وتوثيق OpenAPI
│   ├── emotions/               # محرك تحليل المشاعر والتفاعل العاطفي
│   ├── intelligence_suite/     # محركات الاستدلال وتصنيف النوايا (RCI)
│   ├── server.py               # خادم الـ API المركزي الموحد
│   └── src/                    # واجهات وتطبيقات Android و Jetpack Compose
├── neama_module/
│   ├── NeamaNextGen.py         # وحدة التطوير والابتكار المستقبلي
│   ├── SasaNextGen.py          # توافقية الربط البرمجي
│   └── tests/                  # حزمة الاختبارات الآلية
├── .github/
│   └── security/SECURITY.md    # سياسة الأمان السيبراني
├── CHANGELOG.md                # سجل التغييرات والترقيات المعمارية
├── MAINTENANCE.md              # دليل التشغيل والصيانة الدورية
├── ROLLBACK_PROCEDURES.md      # خطة الطوارئ والتعافي السريع
├── Dockerfile & Procfile       # إعدادات الحاويات والنشر السحابي
├── render.yaml                 # إعدادات النشر على Render
└── requirements.txt            # قائمة الاعتماديات والمكتبات الآمنة
```

## 💻 تعليمات التشغيل والنشر

### 1. التشغيل المحلي (Local Run)
```bash
# تثبيت التبعيات
pip install -r requirements.txt

# تشغيل اختبارات التكامل
python3 neama_module/tests/run_tests.py

# إطلاق الخادم الموحد
python3 app/server.py
```

### 2. التشغيل عبر الحاويات (Docker)
```bash
docker build -t neama-ai-production .
docker run -p 5000:5000 neama-ai-production
```

### 3. النشر السحابي (Cloud & Render Deployment)
المنظومة مهيأة للنشر التلقائي عبر `render.yaml` و `Procfile`. يتم تشغيل الخدمة بمجرد الربط بالمستودع على الفرع `main`.
